# Data, consent and local state

Events carry event_id, name, timestamp, captured anonymous_id/user_id, caller properties and bounded SDK/platform/device/app context. Native recovered crashes retain the original OS/version/build/time; unknown or oversized release metadata is omitted rather than clipped into another release. Explicit track/identify values remain the host app's responsibility. No advertising ID is read and no ATT prompt is shown.

The native module stores SDK-only owner/generation namespaces: iOS Application Support with backup exclusion/protection, Android noBackupFilesDir. Binding uses SHA-256 of the SDK key plus canonical full ingest/config URLs; plaintext keys are not written into binding metadata. Different owners never replay each other's identity, queue, configuration or crashes. A native SDK aggregate is limited to 8 MiB, queue to 1000 events/2 MiB, configuration 1 MiB plus wrapper, recovered crash 256 KiB with bounded frame counts. Existing cloud backups cannot be recalled by this library.

Pending permission keeps telemetry/identity only in memory. Unreadable privacy fails closed. With unavailable native storage/Expo Go, only a fresh explicit optIn after host permission enables memory-only delivery; restart loses that session. Old binaries lacking the new capabilities require a rebuild. Legacy unbound telemetry/identity is discarded; denied/pending choice survives. Old @corlex:* AsyncStorage rows are not automatically migrated; never clear the host's whole store.

SDK choice and observed ATT ceiling are separate. consent:'att' follows actual iOS ATT without asking; denied/restricted overrides a prior grant, and restoration creates a fresh captured generation only when SDK choice permits it. Explicit optOut is not undone by ATT restoration. An owner-only enum marker preserves genuine explicit consent across observational wipes; default grant creates no such marker. Withdrawal fences in-flight/retry/cache/crash work and removes SDK scopes. Immediate process loss during failed disk IO cannot guarantee durable deletion; local refusal remains effective.

Apple declarations conservatively include linked UserID/DeviceID/ProductInteraction/CrashData because identify can associate analytics/crashes with an account. Tracking stays false. The Expo plugin merges declarations without weakening host entries. Your contact/financial/other explicit traits need host review/declarations; a manifest does not establish store or legal compliance.
